Alma GWS CLI

A private command-line tool for accessing your own Google Workspace data.

Alma GWS CLI is a personal utility that runs locally on macOS. It connects to Google Workspace APIs with OAuth 2.0 so a single authenticated owner can read their own Gmail, Calendar, and Drive data from the terminal.

What it does

  • Reads Gmail messages and threads using the read-only scope
  • Queries Calendar events and Drive files on the owner's behalf
  • Stores OAuth credentials locally, encrypted at rest

What it does not do

  • No server component — nothing leaves the owner's machine
  • No third-party data sharing, advertising, or analytics
  • No access beyond the scopes the owner explicitly grants
